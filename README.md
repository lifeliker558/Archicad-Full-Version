## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Integrated Design Environment** — Create detailed plans, sections, and 3D views effortlessly.
- **BIM Technology** — Utilize Building Information Modeling for efficient data and documentation generation.
- **Real-time Collaboration** — Work simultaneously with team members to enhance project workflow.
- **Advanced Library Management** — Manage materials and features with an optimal object handling system.
- **Flexible File Support** — Import and export files in DWG, DXF, and PDF formats, as well as support for Universal 3D and IFC.

### Advanced Features:
- **GDL Technology** — Use intelligent objects for enhanced design capabilities.
- **BIM Server Integration** — Control access to group resources with advanced privileges.
- **Performance Improvements** — The latest updates include optimizations that enhance efficiency and user experience.
